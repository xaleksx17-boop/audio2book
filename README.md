# Аудиокнига → Электронная книга (Audio2Book)

Программа для Windows 10/11 x64: превращает аудиокнигу в текст и сохраняет её как электронную книгу.
Распознавание полностью офлайн (Whisper), интернет нужен только один раз — скачать модель.

## Что умеет

- **Входные файлы:** mp3, m4b, m4a, aac, ogg, opus, flac, wav, wma, mka, webm, ape, wv.
  Папка с файлами = одна книга (файлы сортируются «по-человечески»: 2 раньше 10), каждый файл — глава.
  Оглавление внутри m4b/mka/mp3 тоже становится главами.
- **Название, автор, чтец, год, аннотация** — из тегов; **обложка** — cover.jpg/folder.jpg из папки или встроенная в аудио.
- **Форматы:** EPUB (проходит EPUBCheck без ошибок, подходит для Send to Kindle), FB2, Kindle AZW3 (через Calibre),
  DOCX, TXT, SRT-субтитры и LRC — текст для плеера (AIMP, foobar2000, MusicBee и др. показывают его при прослушивании,
  если положить .lrc рядом с mp3 под тем же именем).
- **Текст:** чистит «галлюцинации» Whisper («Субтитры сделал DimaTorzok», «Продолжение следует…»), убирает зацикливания,
  ставит точки по длинным паузам, заглавные буквы, тире в репликах, разбивает на абзацы по паузам чтеца.
- **Пакетная очередь:** сколько угодно книг, прогресс, скорость и оставшееся время, пауза/продолжение/стоп.
  Работа сохраняется после каждого куска (~15 мин звука): после выключения ПК или закрытия программы «Старт» продолжит с того же места.
  Компьютер не уснёт во время распознавания.
- **Редактор:** правка текста по фрагментам с прослушиванием (F2 — фрагмент, F3 — слушать с подсветкой текста),
  скорость ×0.75–×2, абзацы, объединение фрагментов, поиск и замена по всей книге (удобно исправлять имена героев),
  переименование глав, смена обложки и метаданных, предпросмотр «как будет в книге», повторный экспорт.

## Перевод на другой язык

В строке «Перевод на:» выберите язык — после распознавания программа переведёт книгу и сохранит
перевод отдельными файлами рядом с оригиналом (`Автор - Название [en].epub`). Уже распознанную книгу можно
перевести из меню книги (правая кнопка → «Перевести»). Способ перевода — «Настройки» → «Перевод»:

| Способ | Качество | Цена 10-часовой книги (ориентир) | Доступ из России |
|---|---|---|---|
| Офлайн NLLB-200 1.3B / 600M | дословнее, без интернета | бесплатно | да |
| GigaChat (Сбер) | хорошее | бесплатно в рамках Freemium (40 млн токенов Pro на 12 месяцев) | да, нужны сертификаты Минцифры |
| YandexGPT | хорошее | ~80 ₽ (Lite) – ~300 ₽ (Pro) | да, оплата в рублях |
| DeepSeek | хорошее | ~$0,2–0,4 (deepseek-flash) | да, оплата картой иностранного банка |
| Claude (Anthropic) | лучшее литературное | ~$0,15 (Haiku 5.5) – ~$3 (Sonnet 5.5) | официально нет |
| Любой OpenAI-совместимый | зависит от модели | — | OpenRouter, LM Studio, Ollama… |

Имена героев можно задать в «Именах и терминах» (`Harry Potter = Гарри Поттер`). Перевод правится в редакторе,
вкладка «Перевод». Ключи API хранятся зашифрованными (Windows DPAPI).

## Скорость

| Модель | Видеокарта NVIDIA (RTX 3060) | Процессор (8 ядер) |
|---|---|---|
| large-v3-turbo (по умолчанию) | 10-часовая книга ≈ 20–40 мин | ≈ 5–10 часов |
| small | ≈ 10 мин | ≈ 1–2 часа |

Цифры ориентировочные. На слабом ПК без видеокарты выберите модель **small** или **medium**.

## Установка

1. Скачайте `Audio2Book-Setup-x.y.z.exe` из Releases (или из Actions → последняя сборка → Artifacts) и установите.
2. **Видеокарта NVIDIA (необязательно, но в 10–20 раз быстрее):** скачайте `Audio2Book-CUDA-pack.zip`
   и распакуйте папку `cuda` в папку программы (`C:\Program Files\Audio2Book\cuda`). Нужен драйвер NVIDIA 528 или новее (проверить: команда `nvidia-smi`).
   Программа сама определит видеокарту; если что-то не так — тихо перейдёт на процессор.
3. При первом запуске книги скачается модель (~1,6 ГБ для large-v3-turbo) в `%LOCALAPPDATA%\Audio2Book\models`.
   Если huggingface.co не открывается — в «Настройках» укажите сервер `https://hf-mirror.com`,
   либо скачайте модель вручную (папка с `model.bin`, например `Systran/faster-whisper-large-v3` или
   `mobiuslabsgmbh/faster-whisper-large-v3-turbo`) и выберите её кнопкой «Своя модель…».
4. Для AZW3 поставьте бесплатный [Calibre](https://calibre-ebook.com) — программа найдёт его сама.
   Без Calibre отправляйте на Kindle EPUB через Send to Kindle — Amazon принимает его напрямую.

## Как пользоваться

Перетащите в окно файлы или папку книги → проверьте название/автора (двойной щелчок по ячейке) → отметьте форматы → **Старт**.
Готовые файлы — в `Документы\Аудиокниги в текст\Автор - Название\`. Двойной щелчок по книге — редактор.

Папка с несколькими подпапками-книгами: программа спросит, добавить ли каждую как отдельную книгу
(подпапки CD1/CD2, «Часть 1/Часть 2» считаются частями одной книги).

Можно добавить пункт «Отправить → Аудиокнига в текст» (галочка в установщике).

## Сборка из исходников

Сборку делает GitHub Actions (`.github/workflows/build.yml`) при каждом push в `main`:
тесты → PyInstaller → установщик Inno Setup → portable-zip → CUDA-пакет. Тег `v1.2.3` публикует релиз.

Локально (Windows, Python 3.12):

```
pip install -r requirements.txt pyinstaller pytest
:: положите ffmpeg.exe, ffprobe.exe (+dll) в папку ffmpeg в корне проекта
python -m pytest tests -q
python run.py                                        :: запуск из исходников
python -m PyInstaller packaging\audio2book.spec --noconfirm
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" packaging\installer.iss
```

## Устройство

```
audio2book/core/audio.py        ffprobe/ffmpeg: теги, главы, обложка, нарезка по тишине
audio2book/core/transcriber.py  faster-whisper, авто-GPU с откатом на CPU
audio2book/core/textproc.py     чистка текста, пунктуация, абзацы
audio2book/core/pipeline.py     задание: проект → распознавание → экспорт, продолжение после остановки
audio2book/core/project.py      проект книги (*.a2b.json рядом с результатом)
audio2book/export/              EPUB, FB2, AZW3, DOCX, TXT, SRT, LRC
audio2book/gui/                 главное окно, очередь, редактор, настройки
```

Лицензии компонентов: faster-whisper (MIT), CTranslate2 (MIT), модели Whisper (MIT),
Qt/PySide6 (LGPL v3), FFmpeg (LGPL-сборка, лицензия в папке ffmpeg).
